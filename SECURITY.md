# Security Policy

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting interface for this repository:
open the **Security** tab, select **Report a vulnerability**, and submit the
report privately.

Do not disclose credentials, private corpora, unpublished review evidence,
local filesystem paths, or exploitable details in a public issue.

## Supported Scope

Security review currently covers the default branch and the latest public
Quranic research handoff. Research correctness and grammatical disagreement
belong in the Quranic research review issue form; vulnerabilities, secret
exposure, unsafe file handling, and supply-chain issues belong in a private
security report.
