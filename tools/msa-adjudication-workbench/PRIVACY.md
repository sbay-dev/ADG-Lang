# سياسة الخصوصية المختصرة لمنصة محكِّم العربية

## البيانات التي نجمعها

- الاسم والبريد؛
- أسماء المستخدم الاختيارية في حسابات التواصل، ومنها اسم مستخدم
  واتساب بدل رقم الهاتف؛
- سنوات الخبرة والتخصص والجهة الاختيارية؛
- الموافقات وتعهدات الاستقلال والتعمية؛
- القرارات اللغوية المسجلة في العينة.

## الفصل بين الهوية والنتيجة

تُشفّر بيانات الهوية أولًا بملف EntityCrypt Matryoshka العشوائي
`AES-256-GCM` ومفتاح محفوظ خادميًا، ثم تحفظ في تخزين خاص منفصل عن الأدلة
العامة (ويكون ذلك في الإنتاج عبر Cloudflare R2 بربطين خاصين منفصلين، مع
بقاء Azure مسار رجوعٍ أثناء القطع). وعند تفعيل
`EVIDENCE_ARCHIVE_MODE=d1` مؤقتًا قبل جاهزية R2، تبقى الأظرف العامة والهوية
المشفرة محفوظة حفظًا سلطويًا داخل D1 حتى يكتمل الانتقال. تُحفظ النتيجة
اللغوية في تخزين منفصل بمعرف عشوائي وتوقيع HMAC. لا يصل إلى GitHub الاسم أو
البريد أو حسابات التواصل أو الجهة.

عند إنشاء حساب الاستكمال، يسجل المتصفح مفتاح مرور عام فقط، وتبقى مادته
الخاصة داخل الجهاز أو مدير مفاتيح المرور. تحفظ قاعدة D1 المفتاح العام والعداد
ومعرفًا عشوائيًا، بينما تحفظ بيانات التعريف والمسودة مشفرتين بـEntityCrypt.
لا يحتاج المحكّم الخارجي إلى حساب Microsoft أو حساب المؤسسة.

قبل إنشاء الحساب أو تغيير البريد، ترسل المنصة رمزًا صالحًا لخمس دقائق عبر
Microsoft 365 Graph من العنوان الخادمي المقيّد `notifications@adg.sbay.sa`
عند اكتمال الإعداد، مع بقاء Azure Communication Services مسار رجوعٍ أثناء
القطع. لا يُحفظ الرمز ولا البريد بصورتهما الصريحة في D1؛
تحفظ فقط بصمات HMAC غير قابلة للعكس، مع حد للمحاولات ومهلة لإعادة الإرسال،
ثم تُحذف سجلات التحقق القصيرة الأجل آليًا.

عند توفير ربط `HYPERDRIVE` بخادم PostgreSQL غير محلي يفرض TLS، تستطيع
المنصة استخدام PostgreSQL السلطوي عبر Cloudflare Hyperdrive مع بقاء D1
مسار رجوعٍ وتعافٍ خاصًّا: تُسجَّل الكتابات المتغيرة المقبولة أولًا في D1
بسجل استردادٍ مشفّر `AES-256-GCM` بمفتاح مستقل
`CPOLY_BACKUP_MASTER_KEY` ثم تُطبَّق على PostgreSQL، كما يمكن حفظ نسخ
احتياطية مجزأة مشفرة للمسار الداخلي الخاص بـCPOLY. يدعم ذلك إعادة بناء
الحالة واسترجاع الكتابات المقبولة ضمن حدود الخطة، لكنه لا يعني وعدًا
بانعدام الفقد إذا تعطل Cloudflare D1 وKubernetes/PostgreSQL معًا في الوقت
نفسه. لا يعاد استخدام مفتاح الهوية `ENTITYCRYPT_MASTER_KEY` لهذا المسار.

## الغرض

تستخدم البيانات لتوثيق المشاركة، والتواصل بشأن جولات التقييم عند وجود
موافقة، وقياس وضوح بروتوكول التحكيم. لا تستخدم للإعلانات ولا تباع لطرف ثالث.

## الاحتفاظ والوصول

تُحفظ بيانات الهوية والتواصل وفق المدة المعلنة في إعداد النشر، ومدتها
الافتراضية 365 يومًا. يستطيع صاحب الحساب تسجيل طلب محو من داخل المنصة.
ينفذ الطلب بعد إغلاق مهامه وانقضاء حد الاحتفاظ: تحذف ملفات الهوية الخاصة،
وتزال مفاتيح الدخول والجلسات والبريد وبصمته وإعدادات التواصل، ويستبدل ملف
الحساب بسجل محو لا يحتوي بيانات تعريف. وفي نمط `EVIDENCE_ARCHIVE_MODE=d1`
يعني الإكمال حذف الصفوف والحمولات من المخزن النشط في وقت التنفيذ، لا وعدًا
بمحوٍ ماديٍّ فوري من نسخ Cloudflare D1 Time Travel؛ فقد تبقى لقطات تاريخية
قابلة للاسترجاع حتى انتهاء نافذة `D1_TIME_TRAVEL_RETENTION_DAYS` المضبوطة
وفق الخطة. تبقى النتيجة العلمية المجهّلة وسلسلة الإجماع لأنها لا تنشر الاسم
أو البريد أو حسابات التواصل.

لوحة المتابعة منفصلة على `/admin/`، ولا تفك بيانات التواصل لعرضها إلا بعد
دخول Microsoft Entra والتحقق الخادمي من دور Global Administrator. لا تمنح
حسابات Passkey العامة أي وصول إلى هذه اللوحة.

## الطلبات

يمكن تقديم طلب الحذف من الحساب، كما ترسل طلبات الوصول أو التصحيح إلى
`team@sbay.sa` مع رقم إيصال المشاركة. لا ترسل بيانات شخصية في GitHub أو
تعليقات عامة. تنطبق كذلك
[سياسة خصوصية sbay](https://sbay.sa/privacy).

## الإجماع والنشر

تسجل مشاركة كل دور في حساب مستقل. لا تصبح نتيجة J1 معتمدة إلا بتوقيع J2
على الجذر نفسه، ثم تبقى `approved` مدة استئناف قدرها 14 يومًا. لا تتحول إلى
`published` إلا بعد وصول إيصال مستودع موقّع يثبت قبول سجل الحالة المرتبط.
GitHub مرآة أدلة داعمة وليس قاعدة الحالة السلطوية.

## حدود المرحلة الحالية

هذه المنصة حالة استخدام بحثية للتحكيم وليست خدمة تصحيح لغوي نهائية. الحزمة
التجريبية مرئية للمطورين ولا تدخل دليل الجاهزية النهائي.
