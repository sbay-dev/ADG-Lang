# سياسة الخصوصية المختصرة لمنصة محكِّم العربية

## البيانات التي نجمعها

- الاسم والبريد؛
- أسماء المستخدم الاختيارية في حسابات التواصل، ومنها اسم مستخدم
  واتساب بدل رقم الهاتف؛
- سنوات الخبرة والتخصص والجهة الاختيارية؛
- الموافقات وتعهدات الاستقلال والتعمية؛
- القرارات اللغوية المسجلة في العينة.

## الفصل بين الهوية والنتيجة

تُشفّر بيانات الهوية أولًا بملف EntityCrypt Matryoshka العشوائي
`AES-256-GCM` ومفتاح محفوظ في Azure Key Vault، ثم تحفظ في حاوية Azure خاصة.
تُحفظ النتيجة اللغوية في حاوية منفصلة بمعرف عشوائي وتوقيع HMAC. لا يصل إلى
GitHub الاسم أو البريد أو حسابات التواصل أو الجهة.

عند إنشاء حساب الاستكمال، يسجل المتصفح مفتاح مرور عام فقط، وتبقى مادته
الخاصة داخل الجهاز أو مدير مفاتيح المرور. تحفظ قاعدة D1 المفتاح العام والعداد
ومعرفًا عشوائيًا، بينما تحفظ بيانات التعريف والمسودة مشفرتين بـEntityCrypt.
لا يحتاج المحكّم الخارجي إلى حساب Microsoft أو حساب المؤسسة.

## الغرض

تستخدم البيانات لتوثيق المشاركة، والتواصل بشأن جولات التقييم عند وجود
موافقة، وقياس وضوح بروتوكول التحكيم. لا تستخدم للإعلانات ولا تباع لطرف ثالث.

## الاحتفاظ والوصول

تُحفظ المسودات غير النشطة مدة 90 يومًا، وتُحفظ بيانات الهوية والتواصل مدة
12 شهرًا من إغلاق جولة التحكيم ثم تحذف، ما لم يطلب صاحبها الحذف قبل ذلك أو
توجد موافقة صريحة على جولة لاحقة. يمكن الاحتفاظ بالنتيجة المجهّلة بوصفها
دليلًا بحثيًا بعد حذف الهوية إذا تعذر عمليًا ربطها بالشخص. يقتصر الوصول إلى
سجلات الهوية على منسق التقييم المخول.

لوحة المتابعة منفصلة على `/admin/`، ولا تفك بيانات التواصل لعرضها إلا بعد
دخول Microsoft Entra والتحقق الخادمي من دور Global Administrator. لا تمنح
حسابات Passkey العامة أي وصول إلى هذه اللوحة.

## الطلبات

تُرسل طلبات الوصول أو التصحيح أو الحذف إلى `team@sbay.sa` مع رقم إيصال
المشاركة. لا ترسل بيانات شخصية في GitHub أو تعليقات عامة.

## حدود المرحلة الحالية

هذه المنصة حالة استخدام بحثية للتحكيم وليست خدمة تصحيح لغوي نهائية. الحزمة
التجريبية مرئية للمطورين ولا تدخل دليل الجاهزية النهائي.
