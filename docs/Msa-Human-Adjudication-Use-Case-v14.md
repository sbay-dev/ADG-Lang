# حالة استخدام التحكيم البشري للعربية المعيارية v14

## التصنيف

هذا إصدار برمجي عادي لبناء **حالة استخدام قابلة للفحص** قبل طلب التحكيم
من مختصي العربية. لا يمثل نموذج CNS ولا يعلن جاهزية لغوية نهائية.

## المشكلة التي يحلها

لا يمكن مطالبة محكّمين مستقلين بإنتاج ذهب نحوي وإعرابي من دون:

1. نصوص محددة ومجزأة إلى وحدات قابلة للتعليق؛
2. واجهة تُظهر المطلوب بوضوح؛
3. فصل تام بين التعليق البشري وتوقعات البارسر؛
4. آلية لقياس الاتفاق وإظهار الخلافات؛
5. سجل تحكيم يفسر كل قرار مختلف؛
6. مخرجات قابلة للتحقق وإعادة التشغيل.

يوفر v14 هذه السلسلة كاملة.

## الأدوار

| الدور | ما يراه | ما لا يراه |
| --- | --- | --- |
| أمين الحزمة | النص، التقطيع، المصدر، حدود الأهلية | لا يضيف توقعات البارسر |
| المعلّق A | النص والوحدات وتعليمات البروتوكول | تعليق B وتوقعات البارسر |
| المعلّق B | النص والوحدات وتعليمات البروتوكول | تعليق A وتوقعات البارسر |
| المحكّم | النص والتعليقان بعد إقفالهما | توقعات البارسر |
| مقيّم الإصدار | الذهب المحكّم بعد اكتماله | لا يفتح holdout قبل إيصال الاستهلاك |

يجب استخدام أسماء مستعارة في الملفات المنشورة، وإبقاء الهوية الشخصية
والتراخيص والبيانات الخام خارج حزمة الإصدار.

## ما يعلقه المختص

لكل وحدة:

- `UPOS`;
- رأس العلاقة النحوية وعلاقة UD؛
- فئة الإعراب التقليدي المدعومة ورأس علاقتها، أي الكلمة الظاهرة التي
  يرتبط بها الدور داخل الحالة المقيدة (الفعل للفاعل أو المفعول، والمنعوت
  للنعت، والمضاف للمضاف إليه، والمبتدأ للخبر)، أو قرار صريح بأن الفئة
  غير منطبقة؛
- ملاحظة اختيارية.

`IrabHeadTokenId` ليس تمثيلًا لنظرية العامل بصورتها الكاملة، ولا يطلب
من المحكّم ترميز عامل لفظي أو معنوي أو مقدّر. إنه رابط محدود بين وحدتين
ظاهرتين في النص ضمن فئات الطيار العشر. إذا لم توجد فئة مدعومة أو رأس
لفظي ظاهر يطابق هذا العقد، يسجل المحكّم «غير منطبق» بدل اختراع رقم.

ولكل جملة:

- سلامة التركيب؛
- اكتمال الإسناد؛
- ملاحظة.

عند اختلاف A وB، تبرز المنضدة الخلاف، ولا يقبل المقيّم القرار النهائي ما لم
يسجل المحكّم سبب الحسم.

## التشغيل

افتح محليًا:

`tools\msa-adjudication-workbench\index.html`

بعد تصدير التعليقين والتحكيم:

```powershell
dotnet run --project src\Adg.LanguageEditor -c Release -- `
  evaluate-msa-adjudication `
  --packet <packet.json> `
  --annotation-a <annotation-a.json> `
  --annotation-b <annotation-b.json> `
  --adjudication <decision.json> `
  --report <evaluation.json> `
  --human-report <human-adjudication.json> `
  --conllu <adjudicated-gold.conllu>
```

المقيّم:

- يرفض الحقول غير المعروفة لمنع تهريب تحليل مخفي؛
- يرفض أي حزمة تكشف توقعات البارسر أو تشتق من PADT/PUD؛
- يثبت اختلاف أدوار المعلّقين والمحكّم؛
- يتحقق من تغطية كل جملة ووحدة؛
- يحسب الاتفاق الخام وكابا للحقول الاسمية؛
- يستخدم الاتفاق الخام عندما تكون كابا غير معرّفة بسبب فئة هامشية واحدة؛
- ينتج تقريرًا بشريًا وCoNLL-U وجذور Merkle حتمية.

## تقييم الطيار التقني

الطيار المؤلف تحت
`examples\arabic-text\msa-adjudication-pilot-v1` لا يحتوي توقعات بارسر ولا
يستخدم PADT/PUD. يستعمل معلّقين ومحكّمًا اصطناعيين لاختبار النظام فقط.

| المقياس | النتيجة |
| --- | ---: |
| الجمل | 9 |
| الوحدات | 36 |
| فئات الإعراب المغطاة | 10 |
| الخلافات المقصودة | 7 |
| الخلافات المحسومة مع تفسير | 7 |
| أقل اتفاق محافظ | 0.8888888889 |
| جاهز لتجربة بشرية | نعم |
| صالح كدليل جاهزية نهائية | لا |
| جذر تقرير الطيار | `5b33b06e5844de20d59a0c6af65f82e9054b1d34f5dfcc14cd126b70fbbb9966` |

تُعاد ملفات التقييم والتقرير البشري وCoNLL-U بايتًا مطابقًا عند تكرار التشغيل.

## تجربة البشر الأولى

الخطوة التالية ليست تعريض holdout النهائي للمطورين. بل تشغيل **اختبار
قابلية استخدام** على الحزمة المؤلفة نفسها:

1. مختصان عربيان مستقلان ينفذان A وB؛
2. مختص ثالث يحكم الخلافات؛
3. يملأ كل مشارك نموذج
   `human-usability-evaluation.template.json`;
4. توثق صعوبة الحقول، زمن الإنجاز، وضوح التعليمات، وثقة التعمية؛
5. تُصلح الواجهة أو التعليمات إن ظهرت عقبة؛
6. بعد ثبات البروتوكول فقط، يحصل أمين مستقل على holdout جديد ويختمه.

بهذا لا نستهلك holdout النهائي في اختبار الواجهة.

## حدود الادعاء

- نتيجة الطيار تقنية وليست تحكيمًا بشريًا.
- الاتفاق الاصطناعي لا يثبت صحة أي قاعدة لغوية.
- لا تزال الجاهزية النهائية `FAIL/BLOCKED`.
- لا يصبح التقرير صالحًا لبوابة الجاهزية إلا بحزمة غير مرئية للمطورين،
  ومعلّقين بشريين مستقلين، وتحكيم أعمى، و500 جملة و15,000 وحدة على الأقل.
